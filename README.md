# Student Management System

## Introduction
The Student Management System is a simple C++ console-based project designed to manage student records efficiently. It uses file handling to store student information permanently.

## Features
- Add new student records.
- View all student records.
- Search for a student.
- Delete student records.
- Store student data permanently using file handling.

## Technologies Used
- Programming Language: C++
- Concepts: Functions, File Handling, and Conditional Statements.

## How to Run
1. Download or clone this repository.
2. Open `Project.cpp` in a C++ compiler.
3. Compile and run the program.
4. Follow the menu instructions.

- `Project.cpp` – Main source code.
